DYNEX STATUS

1. Put your logo.png inside public/.
2. Run: npm install
3. Set ADMIN_KEY to a strong private key.
4. Set ALLOWED_HOST to your own 3X-UI hostname.
5. Run: npm start
6. Open http://localhost:3000

For public use, deploy this Node.js app to a Node-capable host. Do not put ADMIN_KEY in frontend files. Customer pages never receive the original subscription URL or VLESS links.
